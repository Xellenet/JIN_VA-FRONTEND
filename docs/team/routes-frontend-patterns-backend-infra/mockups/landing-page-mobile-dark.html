LP3 · every nav item and both auth CTAs are reachable from inside the sheet, and the sheet closes after a selection (onOpenChange(false) on each handler) — the requirements doc calls this out explicitly. Rows are 48px so they're comfortable touch targets. The theme toggle carries a text label here ("Light mode") because a bare icon on touch has no tooltip to fall back on.
DT1 tokens at badge scale, dark theme
Every pill below is bg-<token>/10 text-<token> border-<token>/20 — the idiom --primary and --destructive already use in status-badges.ts.
--success / --warning / --attention / --info / --destructive / --primary
Completed Paid Out Pending Under Review Payout Needs Attention Transfer Failed No-show Withheld Failed Cancelled Confirmed Resolved Expired Refunded
DT1 / DT2 · measured on dark --card: success 8.88:1 · warning 9.22:1 · attention 7.03:1 · info 6.29:1. Every pill pairs its colour with an icon or a distinct label — no colour-only signalling. Note Confirmed (--primary) vs Completed (--success) stay visibly different, which is exactly why --success is not aliased to --primary. Labels are frozen: HELD is "Withheld", never "Held in Escrow".

Questions people ask.

Does JinVa charge a fee?
Yes. JinVa takes a percentage of each completed job, deducted from the artisan's payout — clients pay the price shown on the booking and nothing on top. The percentage is set by JinVa and appears in the artisan's earnings breakdown; we don't publish a figure here because it isn't a fixed public rate.
